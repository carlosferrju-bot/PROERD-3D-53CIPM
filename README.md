# PROERD 3D — 53ª CIPM

Projeto de recriação audiovisual em 3D para o PROERD da 53ª CIPM — Mata de São João/BA.

## Objetivo

Recriar as lições e materiais audiovisuais do PROERD em uma linguagem visual 3D moderna, educativa e apropriada ao público infantil, preservando a mensagem pedagógica e desenvolvendo uma identidade visual consistente.

## Pipeline

- Blender para modelagem, cenas, animação e renderização.
- Python para automação das cenas e tarefas repetitivas.
- GitHub para versionamento e organização do projeto.
- GitHub Actions para automações de renderização quando o pipeline estiver pronto.
- 1920×1080 (16:9) como padrão de vídeo final.

## Identidade

**PROERD 53ª CIPM — Mata de São João**  
**PMBA, uma força a serviço do cidadão.**

## Estrutura

```text
blender/       Arquivos e scripts relacionados ao Blender
assets/        Personagens, referências, logos e recursos visuais
audio/         Narração, música e efeitos
video/         Vídeos de referência e materiais de trabalho
render/        Saídas de renderização
scripts/       Ferramentas auxiliares
.github/       Automação do projeto
```

## Primeiro projeto

Recriação 3D da Lição 03 a partir do vídeo de referência fornecido pelo instrutor.

> Os materiais originais de terceiros devem ser usados apenas como referência e a nova produção deve ser uma adaptação audiovisual original.
